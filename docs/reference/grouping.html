Grouping

group_by() sets the grouping columns. Selectors work, named arguments group by a computed column, and _add: true adds to the existing groups. _drop: false keeps groups for unused factor levels, so summarise() and count() return them with n() = 0, as dplyr does. ungroup() removes grouping, or only the named columns.

Groups are ordered like dplyr’s: sorted by key, factors by level order, and NA last. filter(), mutate(), summarise(), and the slice functions work within groups. _by: groups for a single call and returns an ungrouped table.

$schools = Frame::fromCsv('schools.csv') |> group_by('school');

echo json_encode([
    'groups' => $schools |> group_vars(),
    'n_groups' => $schools |> n_groups(),
    'sizes' => \array_slice($schools |> group_size(), 0, 4),
]), "\n\n";

// Grouped mutate: helpers are evaluated within each group.
echo $schools
    |> mutate(centered: fn ($r, $g) => round($r->score - mean('score')($g), 2), rank_in_school: min_rank(desc('score')))
    |> ungroup()
    |> head(4);

// One table per group.
$parts = $schools |> group_split();
echo "\n", \count($parts), ' tables; the first has ', $parts[0]->nrow(), " rows\n";

Group utilities

Function Returns
group_vars() The grouping column names
n_groups() The number of groups
group_size() Rows per group
group_indices() Each row’s 1-based group number
group_keys() A table of group keys
group_split(_keep:) A list of tables, one per group
group_map(fn ($table, $key)) A list of the function’s results
group_modify(fn ($table, $key)) A grouped table built from the returned tables
group_walk(fn ($table, $key)) The table, after calling the function per group
group_cols() A selector for the grouping columns
cur_group_id() The current group’s number, in mutate(), summarise(), and reframe()
cur_group_rows() The current group’s row numbers, in mutate() and reframe()

Row-wise operations

rowwise() makes each row its own group. Closures in summarise() and vector helpers then see one row at a time. Optional id columns stay as groups in the result of summarise().

echo Frame::fromRows([
    ['id' => 'a', 'q1' => 3, 'q2' => 5, 'q3' => null],
    ['id' => 'b', 'q1' => 4, 'q2' => 1, 'q3' => 2],
])
    |> rowwise('id')
    |> summarise(total: fn ($row) => Stats::sum(
        [...$row->column('q1'), ...$row->column('q2'), ...$row->column('q3')],
        naRm: true,
    ));
# A tibble: 2 × 2
# Groups:   id [2]
  id    total
  <chr> <int>
1 a         8
2 b         7
