phplyr

dplyr and tidyr for PHP 8.5

phplyr is a port of R’s dplyr and tidyr to PHP. It works on phibble tables and is written for the PHP 8.5 pipe operator, so a pipeline reads like its R equivalent.

$schools = DataFrame::fromCsv('schools.csv');

echo $schools
    |> filter(fn ($r) => $r->study_hours >= 5)
    |> group_by('school')
    |> summarise(students: n(), avg_score: mean('score'), sd_score: sd('score'))
    |> arrange(desc('avg_score'))
    |> head(5);
# A tibble: 5 × 4
  school    students avg_score sd_score
  <chr>        <int>     <dbl>    <dbl>
1 school-07       14      86.9     6.32
2 school-06       20      80.9     8.90
3 school-02       12      79.7     8.22
4 school-09       11      79.3     6.67
5 school-11       13      77.6     7.31

Each verb is a function that returns a closure taking one table. The |> operator passes the table from one verb to the next. Verbs call the methods of phibble’s Table contract, so the same pipeline runs on the in-memory DataFrame and on other backends that implement the contract.

Results follow dplyr 1.2 and tidyr 1.3. The test suite runs the same pipelines in R and PHP and compares the output. The reference scripts are in tests/r/.

Install

phplyr needs PHP 8.5.

composer require erikwestlund/phplyr

The optional php-stats extension speeds up the descriptive helpers and provides lm() and glm().

The family

  • phibble provides the typed data frame, CSV and database sources, and the Table contract.
  • phplyr provides the dplyr and tidyr verbs.
  • php-stats is a native extension for statistical models and descriptive statistics.
  • phpolars is a native extension that binds Polars. phibble’s PolarsTable uses it to run the same verbs in Polars.
